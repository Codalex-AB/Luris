# Luris

The online implementation of the card game Luris.

## Play locally

Open [`index.html`](index.html) directly in any modern browser, or serve this folder as a static site. The game is a single self-contained HTML file, so it can also be embedded in an iframe:

```html
<iframe src="https://luris.org/play" title="Play Luris" style="width:100%;height:900px;border:0"></iframe>
```

The current implementation supports a complete solo game against Nova, including set placement, bluffs, flips, swaps, discard management, final-turn scoring, a responsive layout, and a short rules dialog.
