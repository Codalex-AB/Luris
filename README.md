# Luris

The online implementation of the card game Luris.

Luris is created by Jim Westergren in September 2023 and is owner and copyright by Codalex AB. 

This online implementation is created by Codex (AI) and is issued with the MIT license.

The code is javascript and can be run and tested locally in the browser without a web server.

Latest version is running on this URL in an iframe: https://luris.org/play
